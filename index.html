Module 1.1: Ultrasonic Smart Blind-Stick (Acoustics + Algebra + Python)

The Challenge: An ultrasonic sensor sends a sound pulse at $v = 0.034\text{ cm/}\mu\text{s}$. Because the sound travels to the obstacle and back, the total distance covered in echo time $t$ is $2d$. Using the CBSE speed formula: $$d = \frac{v \times t}{2}$$ Fix the divisor in the Python code below so the blind stick triggers its vibration alarm accurately when an obstacle is closer than $50\text{ cm}$!

4000 µs
# 💻 Fix the Math Bug: Change 1 to 2 in the yellow box below!
speed_cm_per_us = 0.034
echo_time_us = 4000
distance_cm = (speed_cm_per_us * echo_time_us) /
print("Obstacle Distance:", distance_cm, "cm")
📏 Real Physical Obstacle: 68.0 cm 🤖 Your Python Output: 136.0 cm
⚠️ MATH BUG! Sound travels there AND back. Change the divisor in the code from 1 to 2!
